pyjs benchmarks

ready docs

The benchmarks of the pyjs repository (benchmarks/: the Python ↔ JavaScript FFI and the asyncio event loop), run in a web worker of this browser, with pyjs and with pyodide (the reference), one after the other. Times are the median per operation; quick measures fewer and shorter rounds than full (what the CI runs). The numbers depend on the machine and the browser: compare the two columns, not with other machines.
