pyjs benchmarks

ready docs

The benchmarks of the pyjs repository (benchmarks/: the Python ↔ JavaScript FFI and the asyncio event loop), run in a web worker of this browser, with pyjs and with pyodide (the reference), one after the other. Each run measures short rounds (shorter than the CI's), and the whole suite runs repeats times per runtime (alternating, each in a fresh worker): a time is the median per operation over the runs, ± their relative standard deviation, and the ratio is taken per run. It is colored only if every run agrees by more than 3% (green: pyjs faster each time, pink: slower each time), grey means within the noise. The numbers depend on the machine and the browser: compare the two columns, not with other machines.
